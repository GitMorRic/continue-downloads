自托管怎么开始？

准备能够访问的 HTTPS 域名和 Docker 主机，解压自托管包，按 deploy/README.md 操作。Windows 使用 deploy/install.ps1，Linux 使用 deploy/install.sh。然后在手机、桌面登录该服务，首次通过电脑 USB 绑定墨水屏。语音识别与大模型需要分别配置。

开发预览：软件与模拟链路已验证，真实手机、墨水屏和付费供应商需分别验收。本页不会触发设备刷机或自动安装。
